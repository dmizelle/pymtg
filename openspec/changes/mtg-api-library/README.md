# mtg-api-library

Create pymtg: A Python library providing a unified interface to Magic: The Gathering APIs with normalized data models for Card Lookup, Deck Aggregator, and Universal Search.

**v1.0 Scope:**
- Scryfall (public API, no auth)
- Archidekt (unofficial API, session auth)
- Moxfield (via Parse.bot wrapper, API key auth)
- TCGPlayer (OAuth2, closed to new developers - implement but cannot fully test)
- Cardmarket (OAuth 1.0a, closed to new developers - implement but cannot fully test)

**Future:**
- Deckbox (no public API currently available - monitor for release)
