

### Commands for Development
- **Testing**: No testing framework is currently set up.
- **Linting/Formatting**: No specific tools are mentioned, but common tools like `flake8`, `black`, or `mypy` can be used.
- **Running**: The module can be imported and used in a Python script.

### Utility Commands
- **Git**: Standard Git commands for version control.
- **Shell**: Standard Linux shell commands like `ls`, `cd`, `grep`, etc.

### Guidelines and Design Patterns
- **Async Support**: The client is designed to support asynchronous requests.
- **Error Handling**: Custom exceptions are used for error cases.
- **Caching**: Caching is left to the consumer.
